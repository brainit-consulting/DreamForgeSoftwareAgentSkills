# Apple HIG Compliance for responsive web apps

An evidence-driven workflow for auditing, planning, implementing, and verifying mobile-responsive web interfaces using Apple Human Interface Guidelines adapted for the web, WCAG accessibility, and browser-native behavior.

This skill is for websites and web apps. It does not generate native SwiftUI or UIKit interfaces, and it does not ask web products to imitate iOS chrome.

## Install

```bash
npx skills add brainit-consulting/DreamForgeSoftwareAgentSkills --skill apple-hig-compliance
```

## What it covers

- Responsive viewport and reflow testing
- Touch-target sizing and spacing
- Adaptive navigation and data-dense layouts
- Accessible forms, dialogs, sheets, menus, and feedback
- Safe areas, zoom behavior, contrast, and reduced motion
- Responsive images, rendering cost, and network lifecycle
- Browser evidence, accessibility-tree checks, and real-device follow-up

## Independence notice

This is an independent community skill. It is not affiliated with, endorsed by, or certified by Apple. "Compliance" describes an evidence-based review target, not a formal certification or guarantee.
